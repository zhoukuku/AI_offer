# 商业上线交接（2026-10-09）

## 已准备

- 免费 2 次终身试用；29 元 / 30 天，100 次成功 AI 请求，每日 20 次。失败退次；一键优化会消耗多次。
- 基础 TXT、DOCX、文字型 PDF 导入、手动编辑和导出免费。图片 OCR / 显式 AI 解析扣次。
- 单段润色及体检建议先对比后确认，支持撤销最近一次应用；撤销不退 AI 调用次数，刷新后撤销记录清空。
- 订单由后端固定金额生成，隔离用户可见范围，支付结算事务内更新权益，重复结算不重复延期。演示订单单独标识，不计真实收入。
- 模型返回 usage 后持久记录输入、输出、缓存 token；包括被业务校验拒绝但模型已产生费用的请求。后台展示最近 30 天费用估算及高用量用户。

模型费用采用可配置的 Flash 高峰单价和参考汇率，不是平台账单。价格来源：https://api-docs.deepseek.com/quick_start/pricing/ 。模型或汇率变化须更新配置；ASR、短信、服务器、支付手续费、税费和获客费用尚未计入，后台金额不能视作净利润。缺少 usage 的上游响应不能核算费用。旧调用不能回填真实账单。

## 启动准备

1. 将 `server/.env.production.example` 复制为 `server/.env.production`，填入随机 AUTH_SECRET、真实管理员手机号及 AI_API_KEY；环境文件不提交 Git。禁用演示模式。
2. Docker 环境执行 `docker compose build`，再执行 `docker compose up -d`。数据保存在独立卷；只绑定本机 8787，由服务器 HTTPS 反向代理对外提供服务。
3. 先在测试环境验证注册、登录、创建/导入、保存、润色对比与撤销、PDF、额度、支付及后台日志；再切正式域名。Docker 构建文件已准备，当前机器未进行镜像构建验收。
4. 正式管理员必须使用独立账号和强密码，不能迁移本地 1/1、2/2 调试账户或测试数据库。生产管理员由 ADMIN_PHONES 指定。

## 备份与恢复

本机运行：`node scripts/backup-db.mjs /安全目录/日期-时间.db`。容器运行：`docker compose exec app node scripts/backup-db.mjs /app/server/data/日期-时间.db`，再从容器复制备份到服务器之外的安全存储。脚本用 SQLite 在线备份接口，包含 WAL 中已提交内容，拒绝覆盖已有文件，文件权限 0600。

恢复前停止应用并保留当前数据库及 WAL/SHM 文件；确认备份 integrity_check 为 ok 后，替换 app.db 并移走旧 WAL/SHM，再启动验证。生产不能对运行中的数据库直接复制覆盖。备份需保护访问权限，定期演练恢复；脚本不是自动备份计划。

## 仍需实际资料后完成

- 服务器系统、规格、部署方式、域名和 HTTPS/备案现状。
- 公司公开名称、客服方式、服务条款/隐私政策的主体和联系方式。
- 微信支付或支付宝的商户类型、商户号、应用信息、证书与密钥配置。
- 短信服务商、签名与模板。当前真实短信尚未实现，生产注册会明确拒绝模拟验证码。

真实支付当前尚未完成；生产拒绝模拟开通。现有订单结算函数只能由服务端可信支付结果调用，未开放无签名回调。接入时必须验证回调签名、解密（微信）、商户与应用身份、订单金额和支付状态，并做主动查单、退款及对账验收。服务商凭据放服务器环境或权限受控的证书文件，不写源码或聊天。

账户找回/注销、真实支付/短信、精确分页预览和完整移动端验收仍需后续工作，当前不应宣称已具备全部商业上线条件。

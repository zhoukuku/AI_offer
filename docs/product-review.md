# 产品对标与闭环改进记录

检查日期：2026-10-09。范围为本项目源码、公开竞品页面、本地 API、浏览器操作与测试；未登录竞品后台，也未复刻其品牌、页面或模板素材。

## 参考与取舍

[超级简历公开首页](https://www.wondercv.com/?locale=zh-CN)强调内容生成、智能诊断、岗位 JD 适配、模板与双语管理；[网申插件页](https://www.wondercv.com/plugin)强调填写效率与简历修改同步。这些是公开产品介绍，不是我们对其效果或通过率的独立验证。

借鉴的是工作流程：真实资料先录入 → 找到内容问题 → 对照目标岗位 → 核实建议 → 保存版本 → 导出/投递 → 复盘。当前阶段优先消除断点，不以增加大量模板或宣称 ATS 通过率作为主要目标。

## 发现与处理

| 原断点 | 本轮处理 |
| --- | --- |
| SQLite 安装版本与声明冲突，原生启动崩溃 | 数据库依赖仅由 server 管理，统一为 11.x；通过临时数据库启动验证 |
| 多处生成后直接覆盖内容 | 统一简历字段类型；生成/优化/适配/区域改写保留原文快照，并提供确认 |
| 编辑丢失、主题单独保存又被正文覆盖 | 串行自动保存、主题与模板纳入同一正文状态、断网草稿恢复、离页刷新保护 |
| 从零生成假公司、技能和成果 | 本地模式只建立空框架；真实模型提示约束事实，应用前由用户核实 |
| 评分、匹配、译文是固定示例 | 本地诊断与匹配改为真实内容规则；翻译需真实模型；错误不再降级成示例成功 |
| JSON 缺少字段导致页面错误 | 每种 AI 任务明确返回结构，校验类型、关键字段与评分范围 |
| AI 对话只发送最后一句 | 文本对话发送历史用户/助手消息；结构化模拟面试保留岗位与对话输入 |
| PDF 同行电话和邮箱拼接 | 按文本坐标保留换行与实际间距，导出的 PDF 可再次导入解析 |
| 免费次数预扣、失败也扣费 | 数据库事务预留，错误或连接未完成时退回；并发测试验证上限 |
| 免费简历只有一份，适配新建失败 | 默认 3 份；支持同简历版本备份；创建与内容持久化原子提交 |
| 注册万能验证码和默认生产管理员 | 移除固定验证码；OTP 过期/尝试限制/发送间隔；生产不创建演示管理员 |
| 面试自定义 ID 覆盖他人记录 | 服务端最终生成 ID；更新不接受 ID、userId、createdAt；验证跨用户隔离 |
| 岗位适配与投递脱节 | 保存目标公司、岗位、JD、简历 ID；投递页跳转面试并预填信息 |
| 复盘失败原始记录不可见 | 先保存再复盘，支持重试和删除，不丢原始回答 |
| 插件没有认证，经历类型不一致 | 插件独立登录并携带 token；按需注入；字符串与数组经历均可填充 |
| 模拟会员返回结构读取错误 | 正确读取 user；权益同步刷新；明确显示无真实扣款 |
| README 把占位能力写成已完成 | 重写能力表、配置、限制与测试说明 |

## 验证方法

- Node 测试启动临时数据库与独立端口，覆盖主流程、权限、并发名额及次数、失败退款和生产开关。
- 本地模型服务替身验证实际 HTTP 请求体、JSON 结构、历史对话、图片输入、multipart 音频与失败行为；不代表真实 DeepSeek 在线服务已验收。
- 浏览器使用 Chrome，实际操作登录、文件导入、修改、自动保存、断网草稿恢复、诊断、分享、打印、岗位匹配、记录投递、预填与保存复盘、演示会员开通。
- 插件内容脚本在浏览器 DOM 中验证字段类型、输入事件、已有值与敏感字段保护；完整扩展仍需在真实目标网申站点人工验收。
- 测试用 PDF / DOCX 均为虚构测试信息；QA 图片与 PDF 位于本地 outputs/qa，不进入仓库。

## 尚未完成的线上能力

1. 当前没有真实 DeepSeek 密钥，尚未进行线上模型质量、耗时与费用验证。填入 server/.env 后应使用本人授权的测试简历逐项验收。
2. 真实短信、支付、订单、回调验签与幂等仍需完成。生产目前不会回显验证码或模拟收款成功。
3. 语音需要转写服务；扫描 PDF 需要逐页 OCR；插件 iframe、Shadow DOM、多段动态表单适配仍有限。
4. 模型任务字段校验可保证结构，不能保证语义真实性；建议始终对照原始经历核实结果。
5. 正式商业部署还需数据库备份、监控、持久化模型用量和部署配置。

## DeepSeek 接入依据

截至检查时，[官方模型表](https://api-docs.deepseek.com/quick_start/pricing/)列出 deepseek-flash 和 deepseek-v4-pro，并说明 Flash 支持视觉。项目默认 deepseek-flash；[官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)说明默认启用思考，本项目明确关闭思考以适合交互式结构化简历任务。配置可以按实际账号支持的模型覆盖。


## 2026-10-09：工作台与简历预览

参考超级简历公开页面（https://www.wondercv.com/）的模板、内容编辑与岗位适配组织方式，优化本项目的核心编辑体验：

- 登录后首先展示简历，按更新时间排序；真实内容缩略图，每次显示六份，可继续展开。保留导入、新建、重命名、复制与删除。
- 导航分为简历与分析、求职进度、求职工具、系统管理；窄屏提供带名称的图标入口和退出按钮。
- 编辑表单与预览分别滚动，章节快捷导航；固定 794px A4 宽度，缩放保持文字换行稳定。支持适应宽度与专注预览，Escape 退出。
- 模板选择和主题色支持键盘操作；字段标签与输入关联。
- 打印样式移除缩放与工具栏，仍由浏览器导出 A4 PDF。长内容页数仅为估计，最终分页以 PDF 为准。
- 登录页不再展示硬编码演示凭据，首页移除未验证的用户规模和成功率数据。调试凭据仅保存在本地数据库与被忽略的 .env。

验证：前端构建通过；六项接口回归测试通过；浏览器验证普通用户登录、实时编辑与自动保存、缩放、专注预览、模板切换、缩略图，以及管理员登录和后台入口；现代横幅 PDF 导出一页 A4，正文可提取且不含预览工具栏。桌面和窄屏布局已检查。
